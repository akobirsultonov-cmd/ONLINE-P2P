# P2P Offline + онлайн-админка

В архив включены: исходный iPhone-проект SwiftUI, `OnlineSync.swift`, изменённые `AppStore.swift`, `SettingsView.swift` и `P2POfflineProApp.swift`, а также `online-server/` (FastAPI, SQLite, веб-админка, Docker Compose, тест API).

## Сейчас готово

- Доступ по паролю к онлайн-админке.
- Создание, изменение и удаление денежных операций, управление курсом, кассой и PDF-контрольными остатками.
- Серверное хранение, версионирование, отклонение конфликтующих изменений.
- Автоматический обмен iPhone ↔ сервер при изменении или открытии приложения; опрос примерно раз в 15 секунд, пока приложение открыто.
- Сохранение офлайн-работы на iPhone. При конфликте сохранённые локальные изменения не удаляются.

## Что нужно сделать перед использованием

1. Разместить `online-server` на сервере с **HTTPS**. Следуйте `online-server/README.md`.
2. Создать уникальные пароли и токены в конфигурации сервера.
3. Собрать и подписать обновлённое приложение iPhone (старое приложение не синхронизируется).
4. Сделать JSON-резервную копию важных данных и настроить первое подключение в меню **Ещё → Веб-админка и синхронизация**.

**Текущее ограничение:** сервер и iPhone не опубликованы и не собраны в IPA. Код проверен статически, API протестирован автоматически; сборку SwiftUI необходимо отдельно проверить в Xcode/Codemagic на iOS. Нет мгновенных push-уведомлений, когда приложение полностью закрыто. Пока рекомендуется один iPhone.
