# P2P Offline

## 2.9.8 — Остаток в PDF по шаблону
- Добавлена отдельная функция «Остаток для PDF» в разделе «Отчёты».
- Можно выбрать Гирифтам/Супоридам, сумму, USD/TJS и дату остатка.
- Остаток не меняет кассу: это контрольная отметка только для отчёта.
- PDF теперь делится на блоки: операции → итоги блока → ОСТАТОК → новая таблица.
- Нумерация операций начинается заново после каждого остатка, как в ручном шаблоне.
- В конце PDF итог показывается только для последнего блока.
- Остатки сохраняются в локальных данных и входят в полную резервную копию/восстановление.
- Версия 2.9.8, сборка 63.

Исправлено автоматическое резервное копирование в iCloud Drive.

- Для unsigned/sideload IPA добавлен выбор папки iCloud Drive через системный Files picker.
- Доступ к выбранной папке сохраняется bookmark-ом.
- Ежедневная автокопия пишет полный JSON в выбранную папку и локально на iPhone.
- Хранятся последние 7 датированных копий + P2P-Offline-Auto-Latest.json.
- В Настройки → Данные видна выбранная папка и можно создать проверочную копию сразу.
- Документы приложения также доступны через Files / Finder благодаря File Sharing.


## 2.9.6
- Исправлена ежедневная автокопия: теперь срабатывает при первом открытии приложения в новый календарный день, а не только спустя 24 часа.
- Исправлена запись автокопии в выбранную папку iCloud Drive.
