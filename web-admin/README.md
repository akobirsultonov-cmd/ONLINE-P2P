# P2P Offline — веб-админка (офлайн MVP)

Откройте `index.html` в браузере на компьютере. Не требуется установка или сервер.

1. В iPhone: **Настройки → Данные → Полная резервная копия**. Сохраните JSON и перенесите его на компьютер.
2. В админке: **Импорт JSON**.
3. Измените операции, остатки PDF или курс/начальные остатки.
4. Нажмите **Скачать копию**.
5. На iPhone: **Настройки → Данные → Восстановить полную копию из iCloud Drive** и выберите новый JSON.

## Ограничения
- Это **локальный редактор резервных копий**, не онлайн-синхронизация. Изменения на iPhone не появляются автоматически.
- Обязательно сохраняйте исходную резервную копию перед восстановлением. Импорт на iPhone заменяет текущие данные.
- Для Swift `JSONEncoder`/`JSONDecoder` даты — количество секунд с 2001-01-01 (учтено в редакторе).
- Вложения в существующих операциях сохраняются как есть. Дополнительные поля операций тоже сохраняются, если не редактируется тип обмена.
- Данные не отправляются в интернет и не сохраняются автоматически после закрытия страницы.
- Публиковать панель с конфиденциальными файлами в открытом интернете нельзя. Для полноценной онлайн-админки понадобятся API, авторизация, база данных и синхронизация приложения.
